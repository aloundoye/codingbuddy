## CodingBuddy 0.5.0

CodingBuddy 0.5.0 brings durable sessions, recoverable background work, and cloud provider routes to the terminal, web, and VS Code.

- **More provider choices.** Use OpenAI Responses, AWS Bedrock Converse, Vertex AI Gemini, Azure OpenAI, or an OpenAI-compatible gateway. Configure a gateway path and tool schema capability profile, or register a native protocol through the compiled Rust adapter interface.
- **Resume work across clients.** SQLite preserves ordered responses, calls, and results. A session stays on its original provider route. To change routes, preview and confirm a portable fork that carries the shareable history. Interrupted tools with unconfirmed effects need local review before retry.
- **Run and recover background work.** Inspect or cancel owned jobs from a later local client. Worktrees capture current tracked content and return a patch for review. Checkpoint previews identify the files to restore and protect unrelated or newer edits.
- **Set clear execution boundaries.** Explicit permission denies apply before saved approvals and hooks. CodingBuddy shows the effective shell isolation before approval. Project runtime settings require workspace trust, child processes inherit a limited environment, and browser RPC uses a fresh token on loopback.
- **See what each route has verified.** Provider status reports configuration, connectivity, fixture evidence, and live results. The deterministic suite covers 18 profiles in streaming and non-streaming modes. Live verification is opt-in and specific to the model and deployment.

### Before upgrading

1. Stop existing CodingBuddy processes before reopening a workspace with 0.5.0. Existing SQLite history is reused. A workspace with only a legacy JSONL event journal imports it once and retains the original archive.
2. Move integration credentials into your environment, keyring, or user settings. Use explicit `process_env.grants` for variables a hook, MCP server, or shell command needs.
3. Review unattended commands that depended on inherited variables or saved shell approvals. Unsandboxed commands require fresh approval. Commands that require isolation are rejected on Windows.
4. Configure cloud deployments in user settings and run `codingbuddy provider check` for an explicit connectivity probe. Use `codingbuddy provider verify` when you want a real tool round trip on that model.
