## CodingBuddy 0.6.0

CodingBuddy 0.6.0 makes every turn async end to end, keeps long sessions on track, and stops asking for your login password.

- **Esc stops a turn right away.** Model requests, shell commands (including PTY output), hooks, language servers, MCP servers, approval prompts and subagents are all awaited on one shared runtime. Esc during a running command kills it within seconds, and also works during retry back-off, slow web fetches and remote MCP calls. Several requests to the same language server or stdio MCP server now run at once instead of queuing.
- **Long sessions remember what matters.** Decisions and corrections from each compaction are kept in `.codingbuddy/session_memory/` and shown to the model again after every later compaction or resume. After a pause of five minutes or more, large old tool outputs are trimmed before the next request. You are warned when the conversation reaches 70% of the context window.
- **Keys in a private file, not the keychain.** Saved provider keys and MCP OAuth tokens live in `~/.codingbuddy/credentials.json` and `~/.codingbuddy/mcp-tokens/` (mode 0600). A key entered in `/connect` is saved by default; Ctrl+O uses it for the current session only.
- **Fewer discarded answers on strong models.** Corrective prompt heuristics are off by default for Claude, GPT and Gemini models and stay on for DeepSeek, Qwen, local and unknown models. Configure them under `agent_loop.heuristics`; `codingbuddy doctor` shows what is active.
- **Undo and approvals you can trust.** `/rewind` can undo changes made by shell commands, not only the file-editing tools. "Always allow" now matches the command family and applies to the next command in the same session, never to chained, piped or redirected commands. `codingbuddy permissions approvals` lists saved approvals and `permissions revoke` removes them.
- **Diagnostics for bug reports.** Logs go to `~/.codingbuddy/logs` (never prompts, responses or tool arguments), every crash writes a report, and `codingbuddy doctor --bundle` packages redacted diagnostics.
- **More.** `codingbuddy session search`, `/rename` that persists, `codingbuddy update` for standalone installs with checksum verification, a JSON Schema for the JSON-RPC protocol and a TypeScript SDK in `sdk/typescript`.

### Before upgrading

1. Keys saved in the OS keychain by 0.5.0 are moved to `~/.codingbuddy/credentials.json` the first time they are used. Set `CODINGBUDDY_CREDENTIALS_FILE` to store them elsewhere, or `CODINGBUDDY_NO_KEYCHAIN=1` to skip the migration.
2. If you rely on the corrective heuristics with a Claude, GPT or Gemini model, turn them back on under `agent_loop.heuristics` (globally or per provider).
3. `codingbuddy update` no longer runs `git pull` in your project. Homebrew, npm and source installs are told their own upgrade command.
